## 关于本仓库

本仓库收录了在组会上分享的 PPT 演示文稿，内容围绕论文：

**RDT-1B: A Diffusion Foundation Model for Bimanual Manipulation**
- 📄 论文：[arXiv 2410.07864](https://arxiv.org/abs/2410.07864)
- 🌍 项目主页：[rdt-robotics.github.io](https://rdt-robotics.github.io/rdt-robotics/)
- 💻 官方代码：[thu-ml/RoboticsDiffusionTransformer](https://github.com/thu-ml/RoboticsDiffusionTransformer)

## 论文简介

RDT-1B 是一个拥有 **10 亿参数**的机器人操作基础模型，基于 **Diffusion Transformer** 架构，在超过 **100 万条**多机器人演示数据上进行预训练。它接受语言指令和多视角 RGB 图像作为输入，预测未来 64 步的机器人动作，天然兼容单臂、双臂等多种现代移动机械臂。
