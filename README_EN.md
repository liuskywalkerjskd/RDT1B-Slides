## About This Repository

This repository contains the presentation slides shared at the group meeting, covering the paper:

**RDT-1B: A Diffusion Foundation Model for Bimanual Manipulation**
- 📄 Paper: [arXiv 2410.07864](https://arxiv.org/abs/2410.07864)
- 🌍 Project page: [rdt-robotics.github.io](https://rdt-robotics.github.io/rdt-robotics/)
- 💻 Official code: [thu-ml/RoboticsDiffusionTransformer](https://github.com/thu-ml/RoboticsDiffusionTransformer)

## Paper Overview

RDT-1B is a robotic manipulation foundation model with **1 billion parameters**, built on a **Diffusion Transformer** architecture and pre-trained on over **1 million** multi-robot demonstration trajectories. It accepts language instructions and multi-view RGB images as input, and predicts robot actions for the next 64 time steps. It is natively compatible with various modern mobile manipulators, including single-arm and dual-arm configurations.
